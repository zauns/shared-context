# Shared Context

A local, multi-project issue tracker and context service used by coding agents through MCP. It is personal infrastructure: one machine, one owner, several projects and several concurrent agents.

## Language

**Project**:
A named container for Issues, Modules, and project context documents. A Project has a short key (for example `SHC`) used to form human-readable Issue keys (`SHC-42`).
_Avoid_: Board, workspace, repo

**Issue**:
A unit of work tracked in a Project. It has a title, a Markdown description, a Stage, a Priority, at most one Assignee, an optional Module, an optional parent Issue, Attachments, Links, and an Activity log.
_Avoid_: Ticket, task, card

**Stage**:
The workflow position of an Issue: `backlog`, `todo`, `in_progress`, `review`, `done`, or `cancelled`. Stage is the board column.
_Avoid_: Status, state, column

**Blocked**:
An orthogonal condition on an Issue, not a Stage. A blocked Issue remains in its Stage and carries a reason. Blocking is cleared explicitly, not by moving the Issue.
_Avoid_: Blocked stage, blocked column

**Priority**:
The urgency of an Issue: `urgent`, `high`, `medium`, `low`, or `none`. Priority is independent of Stage.
_Avoid_: Severity, rank

**Module**:
A project-scoped area of work, such as `frontend-refactor`, `frontend-feature`, or `backend-fix`. Modules group Issues for filtering; they are not workflow states.
_Avoid_: Component, label, tag

**Actor**:
A human or agent that performs an action. Actors are labels for attribution, not security principals.
_Avoid_: User, member

**Assignee**:
The single Actor currently responsible for an Issue. Ownership is exclusive; other interested Actors are not Assignees.
_Avoid_: Owner, assignees, responsible party

**Parent Issue**:
An Issue that groups other Issues. Its progress is derived from its direct children.
_Avoid_: Epic, umbrella issue

**Child Issue**:
An Issue whose Parent Issue is set. A Child Issue has exactly one Parent Issue.
_Avoid_: Sub-task, sub-item, subtask

**Attachment**:
A file retained by the service and attached to an Issue, as opposed to a reference to an external path. Adding or removing an Attachment is an Activity event.
_Avoid_: File, upload

**Link**:
An external URL attached to an Issue. A Link is not an Attachment.
_Avoid_: Attachment, bookmark

**Activity**:
An append-only record of a change to an Issue, including who made it and what changed. Activity is generated by the service, not written directly by Actors.
_Avoid_: Log, comment, history

**Comment**:
A Markdown message written by an Actor on an Issue. A Comment is discussion, not Activity.
_Avoid_: Note, activity

**Claim**:
The atomic act of becoming an Issue's Assignee. A Claim succeeds only if the Issue has no Assignee, or is already assigned to the claiming Actor.
_Avoid_: Lock, checkout, take

**Revision**:
A monotonically increasing number on an Issue, incremented by every mutation. A write may state the Revision it expects; a mismatch is a conflict, not an overwrite.
_Avoid_: Version, ETag

**Context Snapshot**:
A curated read model of a Project intended for an agent starting work: project metadata, counts, blocked Issues, the caller's Issues, recent changes, and allowlisted project documents.
_Avoid_: Summary, dump, prompt
